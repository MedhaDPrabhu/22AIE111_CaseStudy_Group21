#Water Supply Management System
#Overview

The Water Supply Management System is a Java-based object-oriented programming project developed as part of the course:

22AIE111 – Object-Oriented Programming in Java
Department of Computer Science and Engineering
Amrita School of Computing, Amritapuri Campus

#The project helps simulate and manage various operations involved in a water supply system, such as:

-Water usage tracking
-Bill payment
-Leakage reporting
-Supply control
-Consumption monitoring
-Report generation

#The project demonstrates the implementation of core OOP concepts, including:

-Classes and Objects
-Encapsulation
-Association
-Modularity
-Dynamic Data Storage using ArrayList
